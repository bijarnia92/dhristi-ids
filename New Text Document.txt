# 👁️ DHRISTI - Advanced Intrusion Detection System

## 🎯 About
DHRISTI is a premium cybersecurity dashboard with real-time network intrusion detection powered by machine learning and advanced analytics.

## ✨ Features
- **Real-Time Monitoring**: Continuous network packet analysis
- **Threat Detection**: SYN Flood, Port Scan, DDoS, Anomalies
- **Geographic Mapping**: Visualize attack origins worldwide
- **Auto-Blocking**: Automatically block malicious IPs
- **Advanced Analytics**: Historical threat analysis and reporting
- **Beautiful UI**: Hacker-aesthetic dashboard with neon effects
